# Agent Judgment Skills — быстрый режим, глубокая разработка и автономность

**Экспериментальная версия v0.2.** Три совместимых [Agent Skill](https://agentskills.io/). Их эффективность **пока не подтверждена сравнительными испытаниями**.

| Навык | Когда использовать | Как работает |
|---|---|---|
| [`rapid-prototype`](rapid-prototype/SKILL.md) | Быстро набросать сайт, прототип, демо | Сразу реализует; по умолчанию не пишет и не запускает автотесты. Допускает одну быструю проверку сборки/запуска, если она нужна для демонстрации. |
| [`deep-engineering`](deep-engineering/SKILL.md) | Сложный проект, архитектура, качество для продакшена | Анализирует важные решения, делает план и значимые проверки; не зацикливается на повторной диагностике. |
| [`adaptive-autonomy`](adaptive-autonomy/SKILL.md) | Агент сомневается, застревает или упирается в решение пользователя | Выбирает ACT / PROBE / PIVOT / ESCALATE, может рекомендовать подходящий режим. |

**Важно:** быстрый и глубокий режимы — **альтернативы**, их не следует одновременно навязывать агенту. `adaptive-autonomy` дополняет любой из них, но не обязан запускаться на каждую мелкую задачу.

Для глубокой разработки можно дополнительно установить [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills). Мы **не включаем** чужой репозиторий внутрь архива: `deep-engineering` может использовать его подходящие навыки, только если они установлены. `/build auto` в том репозитории по-прежнему требует тестирования.

## Как подключить в Codex

Скопируй нужные папки навыков в `.agents/skills/` проекта. Пример для **fish**:

```fish
mkdir -p .agents/skills
for skill in adaptive-autonomy rapid-prototype deep-engineering
    cp -R /путь/к/agent-judgment-skill/$skill .agents/skills/
end
```

Примеры обращений:

```text
$rapid-prototype Сделай технологичный сайт с анимациями. Мне нужен живой результат, без написания автотестов.
$deep-engineering Продумай архитектуру OCR/VIN и проверь её на эталонных документах.
$adaptive-autonomy Если задача заблокирована, найди информативную проверку или попроси моего вмешательства.
```

Необязательные тесты можно не запускать в прототипе, но **нельзя** обходить разрешения, меры безопасности, требуемые проверки перед разрушительными изменениями или выдавать непроверенный код за проверенный.

## Проверка

```bash
python3 scripts/validate_skill.py
```

Пока проверяется только структура skills. Для оценки поведения есть [`evals/scenarios.md`](evals/scenarios.md) и [`evals/rubric.md`](evals/rubric.md). Нужны реальные сравнения с агентами без навыков, чтобы понять, дают ли они пользу.
